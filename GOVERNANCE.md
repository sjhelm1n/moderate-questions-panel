# Governance

Moderate Questions Panel is currently maintainer-led.

Maintainers set release direction, review contributions, manage security reports, and may delegate ownership of project areas to established contributors. Decisions should be documented in issues or pull requests when they affect public APIs, the database contract, security, or contributor workflows.

Contributors may become maintainers through sustained, constructive participation and demonstrated care for compatibility, security, and the community.

The project uses semantic versioning. Before 1.0, minor releases may contain breaking changes when they are clearly documented.
